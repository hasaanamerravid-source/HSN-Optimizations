HSN-Optimizations 4.0.1-yacl — config menu fix
==============================================

What changed
------------
Rebuilt src/main/java/hsn/optimizations/client/config/HSNYaclConfigScreen.java
so the YACL menu works like the older 3.8 YACL screen, while keeping every
4.0 field.

Also aligned the built-in Behind-camera tooltip with EntityRendererMixin.

Drop HSNYaclConfigScreen.java (and optionally HSNConfigScreen.java) into the
same path in 4.0.1-yacl and rebuild.

YACL helpers now match 3.8
--------------------------
- Coloured on/off BooleanController (not tickboxes)
- Integer sliders with unit labels (blocks, %, FPS, ticks, px)
- Percent options stored as 0..1 doubles, shown as 0..100%
- Real default bindings so YACL Reset goes back to field defaults,
  not whatever value was loaded when the screen opened
- Hover text = what the mixin / HotPath flag actually does
- Profile enum applies HSNPresets.apply + HotPath.rebuild
- CPU summary label via NativeBridge

Behavior text matches 4.0.1 code
--------------------------------
- World shape is ONE control. Setting it also writes circularRenderingEnabled.
  The old separate "Circular rendering" tickbox is gone so you cannot leave
  circularRenderingEnabled=true with worldRenderShape=OFF.
- Smart yield: yield ONLY when the last frame missed ~10 ms
  (HSNScheduler.shouldYield), not "when frames are ahead".
- Performance mode: eases distances toward 70% when FPS dips.
  Adaptive culling still owns the 25-100% scaler.
- Behind-camera: entities behind the camera AND past half their slider
  (decorations / items / XP first). Off by default.
- Sounds: distance only, no frustum. Burst counter increments after allow.
- Hard particle cap: live counter only moves when the cap is on.
- Distant client tick skip does not freeze items / XP.
- Living anim throttle does not cancel tickDeath / tickEffects.
- Laptop power-save reads BAT*/status when present.
- Admit-when-ready is SP/LAN only; remote MP keeps ReceivingLevelScreen.
- Skip empty boss overlay is a real BossOverlayMixin guard.

Tabs (same as built-in 4.0 + FPS Helper)
----------------------------------------
General · Entities · Particles · Rendering · Audio · Server · Extra · FPS Helper
