# HSN-Optimizations

A Fabric mod focused on making Minecraft run better on older hardware (pre-2015 / Intel HD GPUs, etc.) in 2026.

It reduces particles, hides distant entities, lowers shadows, name tags and distant sounds, and gives you performance presets without heavily changing how the game looks.

## Features
- Multiple performance presets (Ultra Low, Safe, Balanced, Quality)
- Hotkeys for quick switching
- Works especially well together with Sodium
- Designed for low-end / old hardware

## Installation
1. Install [Fabric Loader](https://fabricmc.net/use/) for the correct Minecraft version
2. Download the latest release from the [Releases](https://github.com/hasaanamerravid-source/HSN-Optimizations/releases) page
3. Put the `.jar` into your `mods` folder

## Compatibility
- Minecraft: 26.2 (and whatever versions you support)
- Loader: Fabric
- Recommended: Sodium
